# PTC Recurrence Predictor (LightGBM, Top-6 features)

A Streamlit web app built on the experiment in
`01_PTC_recurrence_featurereduction_abaltionstudy/thyroid_cancer_9models_results_pureNoStacking_335PTCpatients_lightGBM_top6_features`.
The deployed model is LightGBM on the 6 ablation-selected features, which had the highest
test AUC of the 9 models compared in that run.

## Quick start

Double-click `run_app.bat`, or run:

```bat
D:\anaconda3\envs\radiomics\python.exe -m streamlit run app.py
```

The browser opens at <http://localhost:8501>.

> The app reuses the existing local conda environment **`radiomics`**
> (`D:\anaconda3\envs\radiomics`), which already ships lightgbm 4.6.0, streamlit 1.50.0,
> shap 0.49.1, scikit-learn 1.6.1 and plotly 6.6 - nothing extra needs to be installed.
> The base anaconda env is not usable here: it has no lightgbm, and its pandas import
> fails because pyarrow 14 was compiled against numpy 1.x while numpy 2.2 is installed.

## Model

- **Features (6)**: `Age`, `Physical Examination`, `Adenopathy`, `T`, `N`, `Response`
- **Cohort**: 335 papillary thyroid carcinoma patients, 90 recurrences (26.87%)
- **Split**: stratified 70/30, 234 train / 101 test, `random_state=42`
- **Tuning**: GridSearchCV with 5-fold stratified CV on AUC; best parameters
  `{'learning_rate': 0.1, 'max_depth': 7, 'n_estimators': 200, 'num_leaves': 31}`
- **Scaling**: LightGBM is trained and served on raw (unscaled) feature values. The
  exported `scaler.pkl` is informational only and is not applied at prediction time -
  unlike the older `01_PTC_recurrence/app.py`, which incorrectly standardised the input
  before calling the LightGBM model.

### Test-set performance (identical to the original notebook run)

| Metric | Value |
|--------|-------|
| AUC | 0.9905 (95% CI 0.972-1.000) |
| Accuracy | 0.9604 |
| Precision | 1.0000 |
| Recall | 0.8519 |
| F1-score | 0.9200 |
| Brier score | 0.0364 |

`train_model.py` has this check built in: every run prints all six test-set metrics next
to the published values with an `OK` / `MISMATCH` flag.

## Pages

| Page | Contents |
|------|----------|
| **Single Prediction** | form for the 6 features, probability gauge, risk category, follow-up suggestion, per-patient SHAP contribution breakdown |
| **Batch Prediction** | CSV upload with template and test-set example downloads; computes AUC automatically when the file contains a `Recurred` column; results exportable |
| **Model Performance** | test-set ROC and PR curves, confusion matrix (follows the threshold slider), global SHAP importance, comparison table of the 9 models |
| **About** | background, modelling workflow, encoding table, cohort distributions, limitations |

The **decision threshold** slider in the sidebar (default 0.50) feeds the single
prediction, batch prediction and confusion matrix.

## Tests

```bat
D:\anaconda3\envs\radiomics\python.exe test_app.py
```

Runs the app headlessly through Streamlit's `AppTest` harness: renders all four pages,
predicts a low-risk and a high-risk profile, re-scores the 101 test cases (asserting the
AUC and accuracy have not drifted) and moves the threshold slider - all without a browser.

## Encoding scheme

| Feature | Type | Codes |
|---------|------|-------|
| Age | continuous | age in years |
| Physical Examination | 5 levels | 0=Diffuse goiter, 1=Multinodular goiter, 2=Normal, 3=Single nodular left, 4=Single nodular right |
| Adenopathy | 6 levels | 0=Bilateral, 1=Extensive, 2=Left, 3=No, 4=Posterior, 5=Right |
| T | 7 levels | 0=T1a, 1=T1b, 2=T2, 3=T3a, 4=T3b, 5=T4a, 6=T4b |
| N | 3 levels | 0=N0, 1=N1a, 2=N1b |
| Response | 4 levels | 0=Excellent, 1=Indeterminate, 2=Structural Incomplete, 3=Biochemical Incomplete |

## Disclaimer

Research and educational use only. The model comes from a single public cohort of 335
patients with no external validation, and response to therapy is a post-treatment
variable, so the tool is a post-treatment risk re-assessment aid rather than a
pre-operative predictor. It cannot replace professional medical diagnosis.

## Deploy on GitHub + Streamlit Community Cloud

This folder is a **standalone deployable app** (repo root = this directory).

### 1. Push to GitHub

```bat
cd 02_PTC_top6_streamlit_app
git init
git add .
git commit -m "Add PTC recurrence LightGBM Top-6 Streamlit app"
git branch -M main
git remote add origin https://github.com/zsgk2003/ptc-recurrence-top6-streamlit.git
git push -u origin main
```

Create an empty repository `ptc-recurrence-top6-streamlit` on GitHub first if it does not exist.

`artifacts/model_LightGBM_top6.pkl` is included so the cloud app starts quickly. If the pickle
cannot be loaded (library mismatch), the app automatically retrains from `data/modeldata_335_PTC.csv`.

### 2. Streamlit Community Cloud (free public URL)

1. Open <https://share.streamlit.io/> and sign in with GitHub.
2. **New app** -> repository `zsgk2003/ptc-recurrence-top6-streamlit`, branch `main`.
3. **Main file path**: `app.py` (repo root).
4. **App URL** (example): `https://ptc-recurrence-top6.streamlit.app`
5. Deploy. First boot reads `requirements.txt` and starts the app.

No secrets are required. Optional: set `PYTHON_VERSION=3.11` in Streamlit advanced settings if the
default Python version fails to install LightGBM.

### 3. Verify after deploy

- Open the public URL and run a **Single Prediction** (default inputs should show ~0% risk).
- Open **Model Performance** and confirm test AUC **0.9905** in the sidebar.
